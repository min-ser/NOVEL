## 2026-11-13 제20~22장 서사·감정 통합 재집필 (최신 원고)

- **제19장 유지:** 무혐의 판정 후 남궁현우가 은서방의 정보를 중립 상단에 흘려 마교 외무당이 독자적으로 공식 소환장을 발행한다.
- **제20장 전면 재집필:** 남궁현우가 가문·후원 원로를 압박하고 차윤겸이 학도 연명서와 여론을 선동한다. 반대 의견도 존재한다. 검증 대련에서 서율은 강도겸에게 패하며 부상과 미완성 검술의 한계를 지킨다. 학관은 소환을 즉시 강제하지 않고 심의한다.
- **제21장 전면 재집필:** 소윤·태경의 소수 보호 의견서, 하연의 문서함 침입자 제압, 하연의 감정적인 사파행 제안과 서율의 거절, 하연의 직접적인 호감 표현, 소윤의 질투와 슬픔을 반영한다.
- **제22장 전면 재집필:** 차윤겸의 선동과 집단 배척, 삼인방 충돌, 하연의 개입, 남궁가의 상층 압박을 반영한다. 학관은 무혐의를 유지한 채 **공식 기술 확인 사절단 파견을 승인**한다. 단, 서율 개인의 동의·결심은 아직 남겨 두고 제23장으로 연결한다.
- **후속:** 제23장에서는 서율의 선택과 출발 조건, 소윤·태경·하연의 이별을 다루고, 제24장에서는 실제 출발을 다룬다. 마교의 직접 강제권은 인정하지 않으며, 남궁가와 마교는 동일 조직이 아니다.
- **문체:** 감정에 맞는 느낌표, 몸짓, 숨, 말의 중단, 표정, 행동으로 분노·질투·슬픔·설렘을 차별화한다.
- **상태:** 20~22장 개정 초고, 전체 24/24장 초고, 최종 확정 전.

## 2026-11-13 제23장 「마지막 인사」 집필

- 학관의 사절단 파견 결정과 **전서율 개인의 동의**를 분리하여, 원주실에서 선택과 조건을 명시한다. 서율은 마공 혐의를 인정하지 않으며 기술 확인·호위·귀환·부상 제한을 조건으로 참여한다.
- 남궁현우와 차윤겸은 파견을 정치적 성과로 받아들이지만, 하연에 대한 윤겸의 집착은 해소되지 않는다.
- 노교두는 정파의 도리와 학관 권력을 구분하며 오래된 기본 검식 교본을 건넨다.
- 백소윤은 연정을 직접 고백하고 서율을 안으며 눈물로 귀환을 부탁한다. 진하연은 선택을 존중하고 돌아온 뒤 답을 듣기로 한다. 윤태경은 서율의 빈자리를 지키겠다고 약속한다.
- **실제 출발은 제24장**. 제23장은 출발 전날 밤에 끝난다. 전서율의 독창 검술은 여전히 미완성이다.
- **상태:** 제23장 초고 작성, 누적 23/24장, 정합성 최종 검수 전.

## 2026-11-13 제24장 「떠나는 사람」 집필 — 제1부 초고 완결

- 제23장 파견 동의·이별에 이어 실제 출발. 학관·마교 양측 인장이 찍힌 조사 범위, 사흘 기한, 동행 호위, 귀환 및 재동의 조건을 확인한다.
- 소윤·태경·하연의 배웅과 남궁현우·차윤겸의 뒤틀린 반응을 대비한다. 서율의 침상에 남은 나무패 **「돌아올 곳」**을 귀환의 상징으로 유지한다.
- 접경 협곡에서 정체불명의 무인들이 습격한다. 서율은 다친 오른손으로 검을 잡지 않으며 보법으로 버티다 호위에게 구조된다. 독창 검술과 검기 모두 **미완성**이다.
- 습격자들이 제15장 검 끝의 기운을 알고 있으나 배후는 확정되지 않는다. **남궁가·마교가 직접 사주했다고 단정하지 않는다.**
- 접경의 중립 회담소에서 마교 외무당 인도인과 만난다. 조사와 안전 보장 조건을 재확인하며 제2부 **《순리의 검》**으로 연결한다.
- **상태: 제1부 제1~24장 초고 완결.** 최종 정합성·문체·사건 인과 검수 및 수정은 별도 단계.

- 전서율은 처음부터 숨겨진 고수가 아니다. 무공 실력은 낮지만 독창적인 검의 흐름을 연구한다.
- 세 친구의 우정과 평범한 일상을 충분히 묘사해 마지막 이별의 의미를 쌓는다.
- 정파 전체를 악으로 규정하지 않는다. 정파의 도리와 제도의 부조리를 구분한다.

- 정사 최종 비무의 공개적 굴욕은 **진하연의 압도적 실력 차이**에서 발생한다. 손가락 사건을 관중에게 언급하지 않는다.
- 명문가 가해 학도생과 진하연을 질투하는 학도생은 **별개 인물**이다.
- 진하연의 사파 도피 제안을 전서율은 **정파의 도리, 친구들과의 추억, 돌아올 곳에 대한 믿음** 때문에 거절한다.

## 2026-11-12 확정 서사·정합성 기준 (최신 우선)

- **이중 갈등:** 전서율의 개인 검술 발전과 정파 내부의 정치적 압박이 병행된다. 서율은 정파의 도리를 존중하며 교육을 성실히 따르고, 독자적인 흐름의 검을 별도로 연구한다.
- **발견 순서:** 진하연이 서율의 독창적인 검술 재능을 **가장 먼저** 알아본다. 이후 백소윤과 윤태경이 반복된 관찰과 변화로 그 가능성을 인식한다. 재능 발견은 즉시 전투 최강이 됨을 의미하지 않는다.
- **발전 단계:** 제1부에서는 관찰·보법·검로의 연결을 통해 효율을 개선하지만 미완성이다. 부상 중에는 의원의 검 사용 금지를 지킨다. **검술의 완성은 제2부 마교 생활 중** 이루어진다.
- **결승의 성격:** 진하연은 정파를 자처하면서 정파답지 않게 서율을 다치게 한 대표에게 분노한다. 상대의 주력 초식과 절초를 압도적으로 무력화하여 관중 앞에서 굴욕을 안긴다. 공개적으로 부상 사건을 폭로하지 않는다.
- **정치적 후폭풍:** 정파 내부에서 패배를 중대하게 다루며, 정파 대표의 가문도 체면·위신·이해관계 차원에서 적극 개입한다. 일부 교두의 양심과 정파의 본래 도리는 여전히 존재한다.
- **두 가해자의 결탁:** 서율의 손을 부러뜨린 정파 대표와 제11장에서 하연·서율을 목격하고 질투한 **별개 남학생**이 이해관계에 따라 작당한다. 가문과 학관 제도의 영향력을 이용해 서율을 축출하려 한다. 대표가 처음부터 하연의 개인적 동기를 알았다고 소급 설정하지 않는다.
- **삼인방에 대한 압박:** 표적은 서율뿐 아니라 그의 친구 윤태경·백소윤에게도 확대된다. 구체적인 괴롭힘과 제도 악용의 수단은 후속 집필에서 납득 가능하게 제시한다.
- **마교 파견:** 두 인물의 모의만으로 자동 확정되는 게 아니라, 학관의 추천·심의·승인 등 제도적 경로와 가문 압력의 인과를 서사에서 보여준다. 정파를 떠나더라도 서율은 처음엔 돌아올 것을 믿는다.
- **시간 순서:** 정사 대표 간 결승은 **제12장에서 이미 종료**. 제16~17장은 재경기나 동일 결승을 쓰지 않고 정치적 파장, 명예 회복 시도, 괴롭힘과 제도적 압박으로 재설계한다.
- **기존 관계:** 제5장 복도 사건 오해는 제6장에서 사과까지 해결됨. 제13장에서 첫 해결처럼 재현 금지. 소윤의 수첩은 일상과 감정을 담는 **개인 일기장**으로 후속 걸스토크의 핵심 물건.

- [ ] 세 사람이 조롱 속에서도 서로를 지킨다.
- **다음 장 연결:** 여자 동기를 노리는 일진 무리.

## 제2막 — 오해와 신경전

### [x] 제5장. 복도의 오해 (초고 작성, 확정 전)
- [ ] 정파 일진들이 여자 동기를 끌고 가 괴롭히려 한다.
- [ ] 진하연과 사파 동기들이 개입해 구출한다.
- [ ] 전서율은 사건의 일부만 목격하고 진하연을 가해자로 오해한다.
- [ ] 전서율은 진하연을 죽일 듯이 노려본 뒤 여자 동기를 데리고 떠난다.
- [ ] **이때 오해는 풀리지 않고 전서율은 사과하지 않는다.**
- [ ] 진하연은 억울하고 당황하면서도 전서율의 기개에 설렘을 느낀다.
- **다음 장 연결:** 두 무리의 반복적인 마주침.

### [x] 제6장. 마주치는 사람
- [x] 복도에서 전서율 3인방과 진하연 무리가 마주친다.
- [x] 진하연이 먼저 빈정거리거나 시비를 거는 투로 말을 건다.
- [x] 전서율은 지지 않고 받아친다.
- [x] 식당·수련장 등에서 일상적인 신경전을 반복한다.
- [x] 사파 동기들이 진하연의 유별난 관심을 눈치채기 시작한다.
- **다음 장 연결:** 정사 대표 선발 비무 공지.

### [x] 제7장. 세 사람의 약속
- [ ] 정파·사파 내부 토너먼트 및 최종 정사 비무 규칙을 소개한다.
- [ ] 세 친구가 함께 비무를 준비한다.
- [ ] 실력은 부족하지만 서로를 격려하는 일상을 그린다.
- [ ] 전서율이 기존 초식과 다른 검의 흐름을 고민하고 있음을 암시한다.
- [ ] 비무의 명예와 정사 간 정치적 긴장을 보여 준다.
- **다음 장 연결:** 정파 내부 토너먼트 개막.

## 제3막 — 패배와 부조리

### [x] 제8장. 첫 번째 패배
- [x] 정파 내부 토너먼트가 시작된다.
- [x] 윤태경이 1차전에서 탈락한다. 백소윤은 제7장에서 출전하지 않기로 결정했으므로 응원과 기록을 맡는다.
- [x] 전서율이 명문가 학도생과 대결한다.
- [x] 상대의 우월한 실력과 가학적인 태도를 묘사한다.
- [x] 상대가 목검으로 전서율의 손가락을 반복 공격해 골절이 의심되는 부상을 입힌다. (정밀 확인은 후속 장)
- [x] 전서율 역시 1차전에서 탈락한다.
- **다음 장 연결:** 규칙 위반과 부상 처리.

### [x] 제9장. 묵인
- [x] 두 친구가 전서율의 부상에 반응한다.
- [x] 고의적 손가락 공격이 비무 규칙 위반임을 드러낸다.
- [x] 교두·심판이 명백한 가혹행위를 외면한다.
- [x] 명문가 영향력과 정사 경쟁이 무징계에 작용한다.
- [x] 전서율은 학관의 부조리를 직접 경험한다.
- **다음 장 연결:** 가해자는 제재 없이 대회를 계속한다.

### [ ] 제10장. 승자의 자격
- [ ] 정파 토너먼트의 후속 경기를 다룬다.
- [ ] 손가락을 부러뜨린 가해자가 정파 대표로 선발된다.
- [ ] 학관과 명문가의 환호, 세 친구의 씁쓸함을 대비한다.
- [ ] 사파 대표 진하연과의 최종 비무가 예고된다.
- **다음 장 연결:** 부상 중에도 홀로 검을 드는 전서율.

## 제4막 — 이해와 호감

### [ ] 제11장. 묶인 검
- [ ] 전서율이 두 친구에게 손과 검 손잡이를 붕대로 묶어 달라고 부탁한다.
- [ ] 부상한 채 홀로 수련한다.
- [ ] 정형화된 정파 초식과 다른, 전서율 고유의 검의 흐름을 보여 준다.
- [ ] 독창적인 검술이 아직 완성되지 않았음을 유지한다.
- [ ] 진하연이 수련을 목격한다.
- **다음 장 연결:** 진하연이 검술의 가능성을 알아본다.

### [ ] 제12장. 알고 있어
- [ ] 진하연은 '그 기술을 사용했으면 결과가 달라졌을지도 모른다'고 말한다.
- [ ] 전서율은 '알고 있어'라고 답한다.
- [ ] 전서율은 정파 학관의 분위기 때문에 그 기술을 비무에서 쓰지 않았다고 밝힌다.
- [ ] 진하연은 기술을 가르치지 않고 그 가능성을 인정한다.
- [ ] 두 사람의 무공관과 가치관 차이를 자연스럽게 드러낸다.
- **다음 장 연결:** 과거 복도 사건에 관한 대화.

### [ ] 제13장. 풀리지 않았던 오해
- [ ] 진하연이 여자 동기 구출 사건을 다시 꺼낸다.
- [ ] 전서율은 진하연이 친구를 구해 주었다는 사실을 알게 된다.
- [ ] 진하연은 전서율이 친구를 지키려 했다는 이유를 이해한다.
- [ ] 두 사람은 서로의 성격과 신념을 인정하며 마음을 연다.
- [ ] **질투하는 별개의 정파 학도생**이 두 사람의 만남을 목격한다.
- **다음 장 연결:** 진하연의 호감과 제3자의 질투.

### [ ] 제14장. 괜히 신경 쓰이는 사람
- [ ] 오해가 풀린 후 달라진 두 사람의 일상을 묘사한다.
- [ ] 진하연이 전서율을 이전보다 자주 의식한다.
- [ ] 여자 동기가 전서율의 다친 손을 자연스럽게 챙긴다.
- [ ] 진하연은 두 사람의 친밀함에 질투와 예민함을 느낀다.
- [ ] 전서율은 그 감정의 이유를 알아차리지 못한다.
- **다음 장 연결:** 사파 동기들에게까지 드러나는 감정.

### [ ] 제15장. 사파 대표의 비밀
- [ ] 사파 동기들이 진하연의 예민함을 경험한다.
- [ ] 전서율 옆에 여자 동기가 있을 때 특히 반응이 달라진다.
- [ ] 사파 동기들의 눈치와 가벼운 장난을 보여 준다.
- [ ] 진하연은 자신의 호감을 쉽게 인정하지 않는다.
- [ ] 여자 동기를 악역이나 가해자로 만들지 않는다.
- **다음 장 연결:** 정사 최종 비무가 임박한다.

## 제5막 — 정사의 자존심

### [ ] 제16장. 정사의 자존심
- [ ] 정사 최종 비무가 성대하게 열린다.
- [ ] 정파·사파의 위신과 정치적 이해관계를 묘사한다.
- [ ] 정파 대표의 자신감과 가문의 기대를 보여 준다.
- [ ] 진하연은 상대가 전서율의 손가락을 부러뜨린 인물임을 기억한다.
- [ ] 두 대표의 대결이 시작된다.
- **다음 장 연결:** 실력 차이가 드러난다.

### [ ] 제17장. 압도
- [ ] 정파 대표가 자신의 주요 초식과 절초를 펼친다.
- [ ] 진하연이 이를 차례로 무력화한다.
- [ ] 관중은 **압도적인 실력 차이**만을 목격한다.
- [ ] 진하연은 전서율의 손가락 사건을 관중에게 언급하지 않는다.
- [ ] 정파 대표는 자신의 모든 무공이 통하지 않는 굴욕을 맛본다.
- [ ] 진하연이 결정적으로 승리한다.
- **다음 장 연결:** 정파 대표의 분노와 괴롭힘 심화.

### [ ] 제18장. 패배자의 분노
- [ ] 정파 대표의 자존심과 체면이 무너진다.
- [ ] 정파 대표는 진하연의 개인적 감정과 전서율의 연관성을 알지 못한다.
- [ ] 일진 무리의 괴롭힘이 더 노골적으로 변한다.
- [ ] 남자 동기와 여자 동기까지 표적이 된다.
- [ ] 학관의 방관 속에 세 친구의 일상이 무너진다.
- **다음 장 연결:** 질투하는 학도생의 모함.

## 제6막 — 마교 파견 음모

### [ ] 제19장. 질투의 씨앗
- [ ] 진하연에게 관심을 갖던 정파 학도생의 질투를 구체화한다.
- [ ] 야간 수련장에서 목격한 두 사람의 친밀감이 동기임을 밝힌다.
- [ ] 손가락을 부러뜨린 명문가 학도생과는 별개의 인물임을 유지한다.
- [ ] 전서율을 학관에서 제거하려는 계획을 구상한다.
- [ ] 학관의 제도적 허점과 정치적 이해관계를 이용할 여지를 만든다.
- **다음 장 연결:** 마교 파견의 명분 형성.

### [ ] 제20장. 마교의 이름
- [ ] 마교 파견의 위험성과 돌아온 사람이 없다는 소문을 소개한다.
- [ ] 질투하는 학도생의 모함이 구체화된다.
- [ ] 학관의 심의·승인 구조와 정치적 판단을 묘사한다.
- [ ] 전서율에게 마교 파견이 통보된다.
- [ ] 두 친구와 진하연이 충격을 받는다.
- **다음 장 연결:** 진하연이 전서율을 찾아간다.

### [ ] 제21장. 나랑 사파로 가자
- [ ] 진하연이 전서율을 찾아온다.
- [ ] 정파 제도와 전서율에 대한 부당한 평가를 강하게 비판한다.
- [ ] 진하연은 전서율에게 사파로 함께 도피하자고 제안한다.
- [ ] 사파에서 그의 검술과 가능성을 인정받을 수 있다고 설득한다.
- [ ] 전서율을 잃을지도 모른다는 두려움과 절박함을 보여 준다.
- **다음 장 연결:** 전서율의 대답.

### [ ] 제22장. 돌아올 곳
- [ ] 전서율은 진하연의 사파 영입 제안을 **거절한다**.
- [ ] 정파의 도리와 정파 제도의 부조리를 구분한다.
- [ ] 두 친구와의 추억, 학관에서의 시간을 소중히 여긴다.
- [ ] 정파인으로서 언젠가 돌아올 곳을 잃고 싶지 않다고 말한다.
- [ ] 진하연은 강하게 설득하지만 끝내 실패한다.
- [ ] 진하연이 마음이 찢어질 듯한 아픔과 무력감을 느낀다.
- **다음 장 연결:** 마지막 작별.

## 제1장 개정 기록 (v0.2)

- **원고:** [`chapters/chapter-01.md`](chapters/chapter-01.md)
- **상태:** 개정 초고 작성, 문장·설정 검수 및 최종 확정 전
- **윤태경(尹泰景):** 정파 남자 동기. 짙은 갈색 머리, 삐죽한 앞머리, 시원한 눈매, 마른 체격. 장난과 허세가 많지만 겁이 나도 친구를 버리지 않는 성격. 도술에 관심이 있다.
- **백소윤(白昭潤):** 정파 여자 동기. 반쯤 묶은 흑갈색 머리, 갈색 눈, 단정한 인상. 수첩을 지니고 다니며 이론·관찰에 강하고 실전에 약하다. 세심하지만 친해지면 장난스럽게 받아친다.
- **첫 만남:** 전서율이 길을 보다가 윤태경과 부딪히고, 백소윤이 두 사람이 엉뚱한 방향을 가리키는 것을 바로잡는다.
- **세 친구의 일상:** 입관식 동행, 정파 시연 감상, 진하연의 사파 검술 감상, 과자 나눠 먹기, 청운관 배정, 저녁 식사까지 함께한다.
- **진하연과 전서율:** 진하연은 전서율을 아직 알아보지 못하며 대화도 없다. 전서율만 그녀의 이름과 검의 움직임을 기억한다.
- **검술 복선:** 전서율은 정파 초식의 멈춤과 진하연의 연속적인 흐름을 비교하지만, 아직 자신만의 검술을 완성하거나 이름 붙이지 않는다.
- **마교 복선:** 파견 제도와 돌아온 사람이 없다는 소문을 들으나 실제 사실로 확정하지 않는다.
- **임시 설정:** 학관 내 청운관·제삼 수련반·입관식의 세 번째 깃발 등은 원고에서 제안된 명칭·연출로, 추후 확정이 필요하다.

## 확정 감정선 — 백소윤·진하연·전서율 (2026-11-12 추가)

**확정된 사용자 설정. 기존 원고에서 빠진 부분이며, 기존 본문에 반영 완료된 것으로 간주하지 않는다.**

- **백소윤의 일기:** 처음에는 본인의 하루, 태경·서율과의 우정, 사건과 감정을 고르게 기록한다. 시간이 흐르며 전서율의 말·행동·상처·검술 연구에 대한 기록이 자연스럽게 늘어나고, 어느 순간 일기의 중심이 서율로 옮겨 간다. 소윤은 자신의 기록 변화가 연정이라는 사실을 곧바로 자각하지 않는다. **서율의 마교 출발 직전에야 자신의 마음을 분명하게 깨닫는다.** 일기장은 향후 '걸스토크' 서사의 핵심 소품이다. 구체적인 공개·열람 사건은 미확정.
- **진하연의 연정:** 서율의 독자적인 흐름의 검술에 담긴 재능을 태경·소윤보다 먼저 알아본다. 이후 서율의 성실함과 가치관에 끌려 남몰래 좋아하게 된다. 그러나 서율·소윤·태경의 오래된 유대, 특히 소윤과 서율의 친밀함을 보며 자신은 그 관계에 끼어들 수 없다고 **스스로 생각**한다. 실제로 배척당한다는 객관적 사실은 아니다. 겉으로는 당당하고 장난스러워도 속마음은 숨긴다.
- **전서율의 시선:** 소윤을 소중한 친구로, 하연을 자신을 이해하는 특별한 인물로 여긴다. 두 사람의 연정을 당연히 알아차리거나 누구를 선택한 것으로 미리 쓰지 않는다.
- **관계의 대비:** 소윤은 *너무 가까워서 늦게 알아차리는 마음*, 하연은 *가까워질 수 없다고 생각해 숨기는 마음*. 서로를 악역으로 만들거나 즉각적인 삼각관계 경쟁으로 단순화하지 않는다.
- **이별 장면:** 출발 전 소윤은 감정을 자각한 채 울며 서율을 안는다. 하연은 멀리서 지켜보며 자신도 안아 주고 싶지만 다가서지 못한다. 하연의 감정은 질투보다 슬픔과 자기 억제에 가깝다. 태경도 이별을 힘들어한다.

### 장별 감정선 보강 계획 (아직 원고 수정 전)

- 1~7장: 세 친구의 생활과 소윤의 일상 기록; 하연과 서율의 오해 해소, 하연의 호기심. 소윤의 감정은 우정으로 읽혀야 자연스럽다.
- 8~11장: 서율의 부상에 대한 소윤의 걱정과 일기의 서율 관련 분량 증가. 하연이 단독 수련 중 서율의 재능을 먼저 발견. 하연이 세 친구의 유대를 관찰하는 장면 추가 필요.
- 12~13장: 하연의 압도적인 결승 승리와 감정적 동기를 먼저 복원해야 함. 소윤의 일기에는 승부뿐 아니라 서율의 반응이 더 많이 남고, 하연은 서율과 대화하면서도 삼인방 사이의 거리를 의식하도록 보강.
- 14~18장: 소윤은 서율 관련 기록이 늘어나는 이유를 아직 정의하지 못함. 하연은 호감을 숨기며 스스로 선을 긋는다. 정파 내부의 정치적 탄압과 검술 성장도 동시에 진행.
- 19~22장: 마교 파견 음모가 현실화되며 소윤의 일기와 하연의 감정이 더 선명해짐. 소윤의 확정적 자각 시점은 출발 직전까지 유보.

## 제15~16장 누적 반영 (2026-11-12)

- **제15장 「사파 대표의 비밀」:** 오른손 제한적 회복 → 보법에서 검로로 연결되는 미완성 흐름 → 소윤을 겨냥한 소문·따돌림·집단 괴롭힘 → 서율의 분노와 통제되지 않은 기운 응집 → 하연의 차단 → 금기무공·사파 내통 의혹 → 소윤의 사적인 일기 고백과 하연의 숨긴 호감. 제15장 파일은 대화에서 작성한 초고를 바탕으로 재구성한 보완본이며 이전 채팅 출력과 문자 단위 동일함을 보장하지 않음.
- **제16장 「정사의 자존심」:** 하연의 의도적 냉대와 서율의 상처 → 소윤의 감정 인식 → 정파 대표 **남궁현우**, 질투 학도생 **차윤겸**의 이름 도입 → 남궁가 비공식 정보망 **은서방**의 배후 조사 → 소문이 간접적으로 마교 외곽 정보망에 도달. 마교는 서율의 존재만 인식하며, 실제 마공 사용을 확인하지 않았고 아직 영입·파견을 결정하지 않음.
- **정합성 고정:** 하연은 서율에게 검술을 가르치지 않음. 제15장 기운은 완성된 검기·완성된 독자 검술이 아님. 소윤은 일기에 친구 이상의 감정을 적었지만, 제23장 이별에서야 사랑과 상실의 무게를 온전히 자각함. 제12장 결승 재현 금지. 제5~6장 오해 재발 금지.
- **제17~20장 과제:** 정파 심의의 증거와 절차, 피해자 소윤의 진술 묵살과 교두들의 대응, 가문 영향력의 구체적 작동, 마교 파견으로 이어지는 정당화 과정의 인과를 설계해야 함. 은서방과 마교 정보망은 직접 내통 관계가 아님.
- **미확정 신규 고유명:** 남궁현우·차윤겸·은서방은 제16장 초고에서 제안된 이름이며 추후 변경 가능.

- 소윤은 두 사람의 가까운 모습을 보고 복잡한 감정을 개인 일기에 기록함. 태경은 서율을 지지.
- 서율의 오른손은 완치되지 않았고 독자 검술은 미완성. 의원 지시로 검 사용을 쉬며 보법을 연구함.
- 제22장 연결: 서율의 잔류 의사서, 학관과 외무당의 협의, 친구들의 마지막 저항과 귀환의 의미.
- 주의: 위쪽 과거 체크리스트의 '집필 전' 등 문구는 과거 기록으로, 이 최신 갱신 현황이 우선함.

## 2026-11-13 감정 표현 개정 작업 기록

- **목표:** 감정의 강도를 대사의 문장부호뿐 아니라 표정·손짓·숨·침묵·시선·신체 반응으로 전달한다. 분노·다급함에 느낌표를 사용하되 모든 대사를 고함으로 만들지는 않는다.
- **적용:** 제20~22장 주요 충돌·걱정·우정 장면의 대사와 행동 묘사 집중 개정. 제21장 기존 하연의 고백 장면은 유지하면서 기다림·설렘·거절의 두려움과 감정 반응을 보강. 제1~19장은 강한 갈등 대사의 일부 문장부호만 보수적으로 조정.
- **보존:** 등장인물, 사건 순서, 마교 소환장, 서율의 부상 및 검술 성장 단계, 하연의 제안과 거절은 변경하지 않았다.
- **후속 구조 수정 필요:** 남궁현우·차윤겸의 학도 여론 조성 및 남궁가의 학관 압박이 제20~22장에 부족한 문제는 **미해결**. 학관의 파견 보류·조건 협상 전개도 사용자 의도에 맞게 **추후 재구성 대상**. 감정 표현 개정이 해당 구조적 문제를 해결한 것으로 표시하지 않는다.
- **검수 상태:** 감정 표현 1차 개정이며, 전 22장의 정밀 문학 편집 완료나 최종 확정은 아니다.
