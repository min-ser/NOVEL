# 《천류관》 제1부 캐릭터 명칭·호칭 확정 규칙

## 개명 확정

- **한서린**: 구 원고 이름 `연서`, 이미지 기획 중 사용한 `연화`·`독고연화`를 폐기하고 통일한 정식 이름.
- **소속**: 사파, **흑월 한가**. 흑도 계열의 거대 명문 무가로 설정. 은발, 접부채, 냉정하고 우아한 태도.
- **일반 친근 호칭**: `서린아`.
- **애칭**: `린`. **진하연이 주로 직접 부르는 호칭**. 다른 인물은 관계와 장면에 맞게 `서린아` 또는 `한서린` 사용.
- **서술문**: `한서린` (조사: 한서린이, 한서린은, 한서린을, 한서린과, 한서린에게).
- **전서율 가문**: **비공개**. 가문명·문장·출신 세력을 임의로 확정하지 않는다.

## 주인공 5인 및 대립 인물

| 인물 | 소속/설정 | 외형·인물 표현 기준 |
|---|---|---|
| 전서율 | 정파 학관, 가문 비공개 | 입학 초기 앳된 소년; 검로는 1부에서 미완성, 오른손 부상 유지 |
| 윤태경 | 정파 학관 | 장난기 많은 소년, 친구에게 충직함 |
| 백소윤 | 정파 학관 | 안경 착용, 수줍고 귀여운 학도, 검술 천재로 만들지 않음 |
| 진하연 | 사파, 적룡 진가 | 당당하고 솔직한 여검객, 서린을 주로 '린'이라 부름 |
| 한서린 | 사파, 흑월 한가 | 은발, 접부채, 냉정한 흑도 명문가 출신 |
| 남궁현우 | 정파, 남궁세가 | 명문가 권력, 서율에게 가해한 인물 |
| 차윤겸 | 정파 학도 | 진하연에 대한 일방적 집착과 질투, 남궁현우와 공모 |

## 시대·복식·장소 연출

- **학관 건축**: 서양 중세 성이 아닌 **조선시대 궁궐·전각·회랑·기와 지붕**을 토대로 한 무협 세계관.
- **복장**: **현대식 학원 교복 + 무협식 겉옷/가문 문장**의 퓨전. 완전한 고전 무협 도포만으로 통일하지 않음.
- **입학 당시 연령감**: 중학생 정도의 어린 학도 이미지. 이전 성숙한 이미지 시안은 성장 후 참고안으로 구분.
- **정파**: 절제된 청색·백색 계열과 단정한 실루엣.
- **사파**: 흑색·적색·자색 계열과 개성 있는 실루엣. 복장은 연령에 맞게 설계.
- **문장**: 전서율의 가문 문장 없음. 진가·한가의 문장은 서로 구분.

## 집필 적용 원칙

- 서술문의 모든 `한서린`을 일괄 `린`으로 바꾸지 않는다. `린`은 진하연의 **직접 호칭**에서 주로 사용한다.
- 기존 1부 사건·대사와 인물의 행동 동기를 개명 때문에 임의로 바꾸지 않는다.
- 개명 이전 이름은 **변경 이력 문서**에서만 설명한다.
