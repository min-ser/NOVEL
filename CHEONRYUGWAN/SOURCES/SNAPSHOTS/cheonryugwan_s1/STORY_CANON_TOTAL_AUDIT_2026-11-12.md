# 《천류관》 서사·설정 통합 검수 — 2026-11-12

## 검수 범위
제1~13장 원고, 기존 README 24장 구성, 기존 FULL_AUDIT, 사용자 최신 확정 설정. **이번 작업은 기획·설정 검수이며 소설 본문을 고치지 않았다.**

## 확정된 사건의 인과
1. 정파 입문, 세 친구의 우정, 정파의 가르침과 독창적인 검술에 대한 의문.
2. 명문가 학도생이 비무에서 서율의 오른손 두 손가락을 골절시킴. 학관이 제대로 제재하지 않음.
3. 서율이 검을 들지 않고 혼자 보법을 연구하던 중 하연이 나타남. **하연이 먼저 가능성을 발견**. 질투하는 별개의 남학생이 목격.
4. 하연은 정파의 도리를 저버린 대표에게 분노하며 정사 결승에서 **압도적으로 무력화해 공개적 굴욕**을 줌.
5. 정파 내부에서 사건이 크게 논의되고 대표의 가문이 체면과 영향력을 지키려 개입함.
6. 대표와 질투 인물이 **서로 다른 동기로 결탁**해 서율을 축출하려 함. 서율뿐 아니라 태경·소윤까지 괴롭힘.
7. 서율은 정파 교육을 따르며 개인의 흐름 검술을 연구하고 점차 효율을 높임. 하연 다음으로 태경·소윤이 재능을 알아봄.
8. 정파의 가르침과 개인 검술 사이의 고민이 깊어지나 제1부에서 완성하거나 정파를 전면 부정하지 않음.
9. 학관의 제도와 가문의 압력이 결합되어 마교 파견이 성립. 서율은 돌아올 것을 믿으며 떠남.
10. **제2부 마교에서** 개인 검술이 완성됨.

## 인물별 동기 및 정보 차이
- **전서율:** 정파의 도리와 교육을 존중함. 재능은 독창적인 관찰·연결 능력이지 초반 압도적 전투력이 아님. 음모를 처음부터 알지 못함.
- **진하연:** 정파 전체가 아니라 정파답지 못한 대표의 행태를 경멸. 서율의 가능성을 최초로 발견하지만 직접 사사하지 않음. 대표를 압도하는 것은 실력과 분노의 표현.
- **정파 대표(골절 가해자):** 공개적 굴욕과 가문 체면 손상으로 원한이 깊어짐. 하연이 서율 때문에 분노했다는 사실을 초기에 알지 못함. 후속에 질투 인물에게 정보를 듣는 계기 필요.
- **질투 인물:** 제11장 목격자. 하연에 대한 감정으로 서율을 제거하려 하며, 가문 쪽과 이해관계가 일치해 결탁. 대표와 동일인 아님.
- **윤태경·백소윤:** 서율의 성장을 목격하고 재능을 인식하는 순서는 하연 다음. 괴롭힘의 피해자이자 서율의 정서적 기반. 소윤의 수첩은 개인 일기장.
- **정파 학관·가문:** 단일 악역 조직이 아님. 체면을 중시하는 세력, 정치적으로 침묵하는 자, 부당함을 아는 교두가 공존해야 함.

## 중대 불일치
- 제12장 현재 원고는 선취 유효타·동점·역전의 **접전**으로 쓰여 확정된 압도·굴욕과 모순. **전면 재작성**.
- 제13장 현재 원고는 접전의 여운과 일부 신체 부담을 전제로 함. 제12장 개정 후 **연결 재검수**.
- 기존 README 제13장 구기획은 제6장에서 끝난 복도 오해를 반복함. 본문 기준 제13장 「말하지 못한 것」이 유효.
- 기존 README 제16~17장은 결승 재연으로 되어 있으나 결승은 제12장에 끝남. **정파 내부 파장과 가문 개입 중심으로 재기획**.
- 현재 원고에는 정파 대표의 가문이 사건을 확대하는 정치적 과정, 두 남학생의 결탁, 친구들에 대한 압박, 태경·소윤의 재능 발견이 **아직 충분히 서술되지 않음**. 후속 원고에서 구체화 필요.

## 연속성 가드레일
- 부상 직후 오른손으로 검 휘두르기 금지; 의원 허락 전에는 보법·관찰·이론 중심.
- 서율은 하연의 검을 그대로 복제하지 않음; 독자적인 원리와 실험으로 발전.
- 가문이 어떤 권한으로 학관에 압력을 행사하는지, 파견 제도와의 연결은 집필 전 설계 필요. 아직 확정되지 않은 구체 절차를 사실로 선언하지 않음.
- 하연이 대표를 압도할 때 사적 원한을 관중에게 폭로하지 않음.
- 제1부 끝에 서율 검술을 완성시키지 않음. 완성은 마교 편.
- 정파 전체를 악으로 일반화하지 않음.
