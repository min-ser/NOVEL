최신 보완 규칙 (기존 원문보다 우선)

  • 전서율: 실시간 1인칭. 모르는 것은 질문하고, 자기 판단을 명확히 말한다. 도움받은 경험을 바탕으로 다른 학도를 돕고 대표로 선출된다. 설아의 감정을 처음부터 꿰뚫어 보지 않는다.
  • 남궁설아: 자존심과 명문가의 관점이 있지만 일방적 악역은 아니다. 소윤에게 한 ‘근본도 없는 기지배’ 발언은 실제 잘못. 목검을 밟은 것은 우연. 구조 이후 부끄러움·시선 회피·어색한 대답이 나타난다. 제갈연을 ‘연’이라고 부른다. ‘흥!’은 포인트에만 사용.
  • 제갈연: 설아를 관찰하고 장난스럽게 놀리는 친구. ‘훗……’을 반복적으로 남용하지 않는다. 전서율이 들을 수 없는 대화는 본편에서 직접 서술하지 않는다.
  • 백소윤: 서율과 함께 이론과 실기를 연습하고 자연스럽게 웃는다. 설아에게서 물건을 돌려받는 모습을 목격. 서율에 대한 연정의 결정적 자각은 제1부 후반까지 축적한다.
  • 윤태경: 서율의 보법과 동작을 가르쳐 주고, 대표가 된 뒤 ‘대표님’이라 장난스럽게 부를 수 있다.
  • 진하연: 기본 반말, 절제되고 단호한 말투. 구조 사고는 고의가 아니며 죄책감이 질투보다 먼저다. 납치·마교 서사와 연계할 때 서율의 무학에 대한 관심을 충분히 축적한다.
  • 호칭 충돌 정리: 구문서에서 ‘대표’는 대회 대표에만 쓰도록 한 규칙이 있으나, 최신 확정 ‘학도 대표’ 직책의 일상 호칭에는 적용되지 않는다.
  • 시점: 서율이 직접 목격하거나 들은 말만 실시간 1인칭으로 서술. 타인의 속마음은 행동과 말로만 암시.

최상위 집필 규칙 — 매 화 작성 전 필독 (v3.3)

이 절은 다른 문체 지침보다 우선한다. 새 화 집필과 기존 화 개편 전에 반드시 본 설정집 전체를 먼저 읽고, 원고 작성 후 아래 항목을 검수한다.

  1. 시점: 전서율의 현재진행형 체험을 따라가는 실시간 1인칭 내면 독백. 독자에게 지난 일을 설명하는 일기체·회고체·전지적 3인칭 금지.
  2. 생각의 흐름: 낯선 환경을 보며 즉각적으로 의심하고, 혼자 추측하거나 착각하고, 때로는 속으로 투덜거린다. 누군가 부르면 생각이 자연스럽게 끊긴다. 예: ‘내가 줄을 잘못 섰나? ……아닌 것 같은데. 어라, 입관패 뒤에 글씨가 있네. 정(正)? 아, 이렇게 구분하는구나.’
  3. 문장 리듬: 독백을 모든 행동에 덧붙이지 않는다. 평상시는 생각과 행동의 호흡을 자연스럽게, 위기·비무는 짧은 생각과 감각·행동 중심으로 속도를 높인다. 서율이 알 수 없는 타인의 내면·밀담은 쓰지 않는다.
  4. 관계: 처음 만난 인물끼리 즉시 친구·연인이 되지 않는다. 작은 접촉, 오해, 공동 경험, 갈등과 신뢰의 축적을 통해 관계를 만든다.
  5. 목소리: 소윤은 수줍고 부끄러워하지만 수동적이기만 하지 않다. 하연은 냉정·절제·단호하다. 서린은 민첩한 암살자형 무인으로 하연에게 사실 중심의 짧은 보고를 하며, 사적인 순간에는 친구다운 말투가 가능하다. 하연은 서린을 주로 ‘린’이라고 부른다. 차윤겸은 질투가 왜곡된 확신과 집착, 점진적인 광기로 변한다.
  6. 용어: ‘세력 대표’는 비무대회 선발자 및 대회 진행 중에만 쓰는 임시 표현. 대회 종료 후 일상적인 직함·호칭으로 쓰지 않는다.
  7. 연속성: 인물 이름(한서린), 가문, 연령대, 부상, 관계 단계, 대회 일정과 기존 확정 사건을 확인하고 충돌 시 먼저 표시한다.
  8. 검수: 집필 전 본 설정집과 개편 계획을 확인하고, 집필 후 시점 이탈·일기체·목소리 혼동·급작스러운 친밀감·대표 호칭 남용을 확인한다.

《천류관》 제1부 개편판 — 인물 성격·대사 바이블 v3.0

적용 원칙

  • 제1부 입학 시점: 중학생 정도의 앳된 학도. 행동과 판단에 미숙함이 드러나되 능력은 인물별로 다르다.
  • 세계: 조선 궁궐식 전각·회랑·기와와 현대식 교복을 결합한 퓨전 무협 학관. 정파(청백)·사파(흑적/자흑) 소속 및 가문 문장을 복장에 표시한다. 마교 교류/파견 제도는 별도 설정 검토.
  • ‘세력 대표’는 비무대회 선발전에서 선발된 출전자를 설명하는 문맥에서만 사용한다. 입관식 시연자는 ‘시연 학도’, ‘초청 시연자’, ‘선배’ 등으로 부른다. 대회 종료 후에는 ‘대표’ 호칭을 쓰지 않는다. 대회 전에도 상시 직함처럼 쓰지 않는다.
  • ‘린’은 한서린의 애칭. 진하연이 한서린을 부를 때 주로 사용한다. ‘서린아’는 친근한 직접 호칭. 서술에서는 ‘한서린/서린’ 사용.
  • 암살자형 민첩함은 한서린의 기질·훈련 스타일. 미성년 학도가 실제 암살을 저질렀다는 설정을 자동 추가하지 않는다. 정찰·은신·관찰·잠입 기술의 강점으로 묘사한다.
  • 인물의 개성은 말끝뿐 아니라 대답까지의 시간, 행동, 숨기는 감정, 관계에 따라 달라진다. 느낌표는 감정이 실제로 터질 때 사용한다.

전서율 — 온화한 관찰자, 원칙을 포기하지 않는 신입

  • 평소: 상대의 말을 듣고 엉뚱하지만 구체적인 질문. 칭찬은 솔직하게. 낯선 상황에 머뭇거린다.
  • 화날 때: 평소보다 말수가 줄고 핵심을 정면으로 묻는다. 감정이 한계에 닿으면 목소리가 커진다.
  • 검술: 정파 기본 검식의 ‘끊김’을 질문. 제1부에는 미완성, 오른손 손가락 부상 지속.
  • 예시: “그런데… 그다음 동작은 왜 거기서 끝나는 거야?” / “그건 잘못됐어. 적어도 난 그렇게 배우지 않았어.”
  • 금지: 첫날부터 천재 고수처럼 단정하거나 다른 세력의 무공을 알아보는 듯한 독백.

백소윤 — 수줍고 귀여운, 관찰과 기록에 강한 친구

  • 외형: 안경, 단정한 청백색 교복, 귀여운 치마 디자인. 초기에는 비무 최강자가 아닌 이론·기록에 강한 학도.
  • 평소: 처음에는 존댓말과 조심스러운 질문, 친해지면 반말이 섞임. 당황하면 말이 끊기거나 엉뚱한 정정을 한다.
  • 좋아하는 사람 앞: 시선을 피하고 안경을 고쳐 쓰거나 수첩을 핑계로 감정을 숨긴다. 필요할 때는 의외로 단호하다.
  • 예시: “저, 혹시… 여기 앉아도 될까요?” / “아, 아니! 그게 아니라… 다치면 안 되니까.” / “그건 사실이 아니잖아.”
  • 금지: 모든 문장에 더듬기, 무조건 수동적이거나 질투만 하는 역할.

진하연 — 냉정한 판단, 날카로운 자존심, 드물게 드러나는 온기

  • 소속: 사파, 적룡 진가. 학관 내 뛰어난 무인. ‘사파 대표’는 대회 선발 후 해당 대회 문맥에서만.
  • 평소: 짧은 문장, 불필요한 해명 없음. 말보다 먼저 상황을 파악. 상대를 조롱할 때도 목소리를 높이지 않음.
  • 서율 앞: 무심한 척하지만 질문을 한 번 더 하고 시선이 오래 머문다. 마음이 무너질 때만 문장이 길어짐.
  • 한서린에게: 주로 “린.”이라고 부르며 정보·상황을 묻는다. 친한 친구이므로 명령만 내리는 상관으로 만들지 않는다.
  • 예시: “비켜.” / “검을 내려. 지금은 네 손이 먼저야.” / “린, 확인했어?” / “……가지 말라는 말은 안 할게. 그래도 싫어.”
  • 금지: 늘 발랄한 농담꾼, 설명을 장황하게 늘어놓는 인물, 서율을 대신해 모든 문제를 해결하는 역할.

한서린 — 흑월 한가, 그림자처럼 민첩한 관찰자

  • 소속: 사파 흑월 한가. 은발, 접부채, 자흑색 계열 교복. 잠입·정찰·은신과 상황 판단에 강함.
  • 하연에게 보고할 때: 핵심부터. 확인 사실 / 미확인 / 위험 / 권고를 구분하는 짧은 보고체.
  • 평소: 간결하고 건조한 말투. 가까운 하연에게는 무표정한 농담도 가능. 서율에게는 처음에는 거리감을 둔다.
  • 예시: “린, 상황은?”(하연) / “정문 이상 없음. 서쪽 회랑, 낯선 발자국 둘. 소속 미확인.”(서린) / “하연아. 네 표정은 보고하지 않아도 다 보여.”
  • 금지: 모든 대화를 보고서처럼 말하기, 순간이동 수준의 초능력, 정체불명의 실제 살인 경력 부여.

윤태경 — 수다스럽고 의리 있는 행동파

  • 평소: 먼저 말을 걸고 과장하며 분위기를 풀어 줌. 먹는 것과 수련에 관심. 허세가 있지만 쉽게 들킴.
  • 위기: 친구를 모욕하면 즉시 반응, 화가 나면 말이 빨라지고 거칠어짐. 서율과 달리 먼저 몸이 나감.
  • 예시: “야! 내 말 끝까지 들어 봐!” / “아니, 그건 좀 억울하지 않냐?” / “내가 앞에 설게. 넌 뒤에 있어.”

남궁현우 — 정파 남궁세가의 체면과 서열 의식

  • 평소: 정중한 어휘로 서열을 확인시키고, 직접 욕설보다 비꼼을 사용.
  • 분노: 체면이 무너질 때 존댓말이 깨지고 공격성이 노출.
  • 예시: “기초를 의심하는 것과 기초도 모르는 것은 다른 일이지.”

차윤겸 — 진하연에 대한 집착, 질투가 폭주하는 광기

  • 핵심: 진하연을 한 사람으로 존중하기보다 자신이 인정받아야 할 대상으로 착각한다. 그녀의 무관심과 거절을 받아들이지 못한다.
  • 평소: 예의와 침착함을 연기하며 하연의 주변 사람들을 살핀다. 서율에 대한 질문에는 지나치게 구체적인 관심을 보인다.
  • 발화 변화: 처음에는 조심스럽고 낮은 말투 → 질투가 쌓이면 같은 질문을 반복하고 상대 말을 끊음 → 통제력을 잃으면 웃음과 분노가 엇갈리고 목소리가 비정상적으로 차분해지거나 갑자기 폭발한다.
  • 행동: 하연과 서율이 함께 있었다는 사소한 장면에도 집착한다. 자신에게 유리한 해석만 믿고, 소문을 퍼뜨린 뒤에도 스스로 정당화한다.
  • 주의: 광기는 단순한 고함이나 만화적 악역 웃음이 아니다. 선택적 기억, 왜곡된 확신, 통제 욕구, 선을 넘는 행동의 누적으로 표현한다. 하연의 선택에 책임을 돌리지 않는다.
  • 예시: “아니야. 하연이 그럴 리 없어.” / “내가 먼저였어. 내가 먼저 알고 있었는데.” / “웃지 마. 지금 웃을 일이 아니잖아. ……왜 너만 보면 웃는 거지?”

서술 시점 — 전서율 1인칭 고정

  • 본편 기본 시점은 전서율의 1인칭 ‘나’. 서율이 직접 보고 듣고 느끼고 추측한 것만 서술한다.
  • 타인의 내면·비밀 대화·원거리 사건을 전지적으로 설명하지 않는다. 필요한 정보는 관찰, 대화, 편지, 소문, 이후 확인을 통해 드러낸다.
  • 감정은 서율의 감각·몸의 반응·생각으로 표현하고, 미리 결론을 해설하지 않는다.
  • 인물 관계는 우연한 한 번의 만남으로 확정하지 않고 반복된 접촉과 공동 경험으로 천천히 발전시킨다.
  • ‘세력 대표’는 비무대회 선발과 대회 참가 시에만 사용하는 임시 지위이며 평상시 호칭으로 쓰지 않는다.

대사 작성 체크

  1. 이름을 가리고 읽어도 말하는 사람이 구분되는가?
  2. 대사 직후 표정·손짓·시선이 감정에 맞는가?
  3. ‘대표’가 대회 이외의 상시 호칭으로 쓰이지 않았는가?
  4. 소윤은 수줍지만 필요할 때 스스로 행동하는가?
  5. 하연의 냉정함과 서린의 보고체가 서로 다르게 들리는가?
  6. 서린의 보고는 관찰된 사실과 추측을 구분하는가?
  7. 원고의 사건·부상·대회 시점과 모순되지 않는가?

서술 시점 추가 규칙 (v3.2)

  • 전서율의 실시간 내면 독백형 1인칭으로 작성. 하루를 회고하거나 독자에게 설명하는 일기체를 피한다.
  • 상황 → 즉각적인 의문·착각·감정 → 행동 → 외부 대사로 생각이 끊기는 흐름을 우선한다.
  • '나는 생각했다/느꼈다/보았다'를 반복하지 않고, '……응?', '뭐지?', '아, 그런 건가.' 같은 자연스러운 혼잣말로 전달한다.
  • 내면 독백을 과용해 장면 진행이 지체되지 않게 하며, 중요한 사건은 행동과 대사로 전진시킨다.
  • 서율이 모르는 타인의 속마음과 비공개 대화는 서술하지 않는다.

제1화 확장 집필 보충 (v3.5)

  • 윤태경: 자연스러운 ‘정보 전달자’ 역할. 소문과 유명 인물을 아는 척하며 소개하되 일부는 부정확하고, 질문을 받으면 모른다고 인정한다. 장황한 세계관 강의 금지.
  • 백소윤: 태경의 단순화·편견을 기록과 자료로 조심스럽게 정정한다. 아는 것을 말할 때만 잠깐 자신감이 드러난다.
  • 진하연: 무력뿐 아니라 태도와 판단에서 압도적인 첫인상을 남긴다. 냉정하게 규칙을 확인하고 차별 앞에서 짧게 행동하며, 친절한 설교나 영웅 연설은 하지 않는다.
  • 전서율: 진하연에게 첫날부터 연심을 느끼지 않는다. 검의 흐름에 대한 이해되지 않는 호기심, 그녀의 태도에 대한 경계와 존중이 공존한다.
