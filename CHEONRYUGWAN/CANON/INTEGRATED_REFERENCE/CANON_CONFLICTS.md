# 《천류관》 충돌·미확정 사항 관리표

| 항목 | 과거 문서 | 최신 결정/방향 | 처리 |
|---|---|---|---|
| 대표 호칭 | 비무대회 외 ‘대표’ 금지 | 학도 대표는 공식 직책 ‘대표’ | 문맥 분리 |
| 24화 분량 | 24화 구성 | 자연스러운 분량으로 확장 | 구판 보존, 신판 화수 재설계 |
| 제1부 결말 | 마교 교류 파견 | 마교의 능력 흡수 목적 납치 | 구판 결말 개편 필요 |
| 마교 흡수 | 구판 없음 | 흡수 불가능, 서율은 마교식 무공 학습 | 확정 방향 |
| 남궁설아 | 기존 말투 문서 독립 항목 없음 | 갈등·선행 목격·구조·질투 추가 | 신규 반영 |
| 제갈연 | 기존 말투 문서 독립 항목 없음 | 설아 친구, ‘연’, 장난 ‘훗……’ | 신규 반영 |
| 부상 | 현우가 오른손 손가락 둘 부상 | 구조 사건 팔 부상 추가 | 순서·회복 미확정 |
| 하연 대련 사고 | 기존 대련/대회 | 관객 설아에게 우발적 위험 | 사고 기전·안전 관리 미확정 |
| 마교 납치 주체 | 기존 교류 제도 | 전체 명령 또는 일부 독단 | 미확정 |
| 백소윤 감정 자각 | 구판 23장 중심 | 후반에 점진적 자각 | 확장 화수에 맞춰 재배치 |

**주의:** 원본에 기록된 사실을 최신 확정 설정으로 자동 승격하지 않으며, 신규 장면은 집필 전 연속성 검수 필요.
