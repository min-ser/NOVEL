# 천류관 Novel Archive

**공식 통합 자료실 / 2026-11-19**

Novel Archive는 영어로 자연스러운 명칭이며, 한국어로는 **천류관 소설 통합 아카이브**를 의미한다.

## 최신 자료 진입점
- `00_LATEST_INTEGRATED_CANON/`: 기존 통합 설정집(인물·말투·관계·충돌)
- `00_LATEST_INTEGRATED_CANON/CHARACTERS/`: 주요 인물 9명의 개별 Markdown 설정집과 인덱스
- `01_SOURCE_SNAPSHOTS/`: 기존 원본 자료
- `02_ORIGINAL_VERSION_ZIPS/`: 과거 버전 ZIP 보관
- `03_NOVEL_24_CHAPTER_BASELINES/`: 구버전 소설 원고
- `04_WORKING_COMBINED_24_CHAPTERS/`: 작업 중 통합 원고

## 중요한 상태 표시
**자료 구조 통합 완료 ≠ 모든 과거 대화와 원고의 세부 내용 검증 완료.**
캐릭터별 문서는 현재 확보된 초안이므로 세부 설정 누락 가능성이 있다. 이번 작업은 내용을 임의로 확장하거나 확정하지 않고, 두 기존 아카이브를 하나의 자료실로 병합했다. 기존 파일 삭제 없음.


## 2026-11-19 캐릭터 원문 근거 보강
